## Important implementation instruction
Before writing code, inspect the existing repository and Supabase project. Compare the current implementation with these documents, report conflicts and gaps, and propose a migration plan. Do not overwrite existing work or apply destructive database migrations without explicit review.

These documents capture the agreed product direction, but technical details such as provider selection, shipping policy, retention periods, consent workflow and final database naming must be validated before production. Technical implementation is not a substitute for legal review.
